# RAG Showcase Banner Generation Prompt

## 1. Generation Mode

Built-in image generation produced the text-free source artwork. The project title
and seven exact approach aliases are browser-rendered typography owned by
`rag-showcase-banner.html`, which records the 3:1 composition contract. The complete
composition is published at 3600 x 1200 pixels as `rag-showcase-banner.png`.

## 2. Prompt

> Use case: ads-marketing. Asset type: wide open-source project README brand-banner
> source artwork. Create a polished, sophisticated abstract systems visualization
> in an ultra-wide 3:1 composition: seven clearly distinct luminous data streams
> travel from left to right through layered document fragments, vector lattices,
> retrieval pathways, and a central knowledge-graph structure, then converge into a
> precise measured comparison surface on the right. The subject is rigorous
> side-by-side retrieval-augmented generation evaluation, not generic AI. Near-black
> background with restrained cyan, emerald, violet, and amber accents; crisp
> geometry; editorial technical-art direction; high contrast; strong horizontal
> movement; generous safe margins; suitable for GitHub dark and light page contexts.
> No text, no letters, no labels, no logos, no UI panels, no cards, no people, no
> brains, no robots, no planets, no arrows, no dangling lines, no bokeh, no
> decorative orbs, no stock-photo look. Keep all seven streams visually
> distinguishable and keep every line connected cleanly with no overlaps that
> obscure the structure.

## 3. Asset Roles

- `rag-showcase-banner-art.png`: original generated source artwork.
- `rag-showcase-banner.html`: deterministic 3:1 crop, project title, and lane-label master.
- `rag-showcase-banner.png`: high-resolution opener distributed to all three docs surfaces.
